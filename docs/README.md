# Hello World — Joey Saade

EECE 435L Lab 11, version 1.0.0. Student ID: 202305993.

This console application prints `Hello, World from Joey_Saade!` and exits
successfully. It does not access the network or collect data.

Windows: run `helloworld.exe` from the installation directory shown in the
user guide. Requires Windows and .NET Framework 4 (included on the test machine).

Linux: run `helloworld` after installing the DEB or RPM package. Requires an
x86-64 Linux system with glibc 2.34 or later (the package manager checks this).

See `help.txt` and `user_guide.txt` for usage and uninstall instructions.
